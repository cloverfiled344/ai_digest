# 🛡 Antiscam — разборы мошеннических схем

Третий бот в этом репозитории, рядом с AI-дайджестом и «Идеями дня». Он публикует в Telegram-канал до **10 разборов в день** реальных историй о мошенниках:

- 🧭 **СНГ** — 5 разборов в день. Приоритет у Кыргызстана, затем Узбекистан и Казахстан, потом Россия и остальные.
- 🌍 **Мир** — 3 разбора: Европа, Азия и другие страны.
- 🇺🇸 **США** — 2 разбора.

Каждый пост начинается с места событий жирным шрифтом, дальше идут блоки «Что случилось», «Как работает схема», «🚩 Признаки обмана», «✅ Как защититься» и ссылка на источник. В постах про США и мир есть ещё блок «🌍 Может ли это случиться у нас?».

```
📍 🇰🇬 Кыргызстан, Бишкек
⚠️ Задаток за квартиру, которой нет
…
#разбор #мошенники #СНГ #Кыргызстан
```

Расписание: 8:19, 9:49, 11:19, 12:49, 14:19, 15:49, 17:19, 18:49, 20:19 и 21:49 по Бишкеку. Каждый запуск публикует один пост, и рубрики идут по плану дня. Если в рубрике по плану свежих историй нет, бот берёт другую. Если пусто везде, он публикует напоминание о типичной схеме, но не чаще раза в день. Посты про США и мир, а также всё, что выходит с 23:00 до 8:00, уходят без звука.

## Настройка

Ключ Claude общий с дайджестом (`ANTHROPIC_API_KEY`). Добавить нужно только бота и канал.

1. **Бот.** Создай его в [@BotFather](https://t.me/BotFather) → `/newbot` и сохрани токен.
2. **Канал.** Добавь бота в канал администратором (Edit → Administrators → Add Admin) с правом **Post Messages**. Посты выходят от имени канала, с его названием и аватаркой.
3. **Секреты.** **Settings → Secrets and variables → Actions → New repository secret**:

   | Секрет | Значение |
   |---|---|
   | `ANTISCAM_TELEGRAM_TOKEN` | токен бота от BotFather |
   | `ANTISCAM_CHAT_ID` | `@адрес_канала`, а для приватного канала — число `-100...` (см. шаг 4) |

4. **Проверка.** **Actions → «Antiscam — проверка подключения» → Run workflow**:
   - `send_test_message` — в канале появится «✅ Бот подключён»;
   - `find_chat_id` — нужно для приватного канала. Сначала опубликуй в канале любое сообщение, потом запусти: в логе будет id вида `-100...`. Сохрани его в `ANTISCAM_CHAT_ID`.
5. **Посмотреть пост.** **Actions → «Antiscam — разборы» → Run workflow**. Галочка «Тест» стоит по умолчанию: пост появится в логе, в канал ничего не уйдёт. Можно выбрать рубрику `CIS`, `USA` или `WORLD`.
6. **Запуск.** Тот же workflow со снятой галочкой отправляет пост в канал. Дальше бот работает сам.

⚠️ Репозиторий публичный, поэтому логи Actions видны всем. Секреты в логах скрыты, а посты и так публичные.

### Необязательные переменные (вкладка Variables)

| Переменная | Пример | Что даёт |
|---|---|---|
| `ANTISCAM_CTA` | `🔍 Проверь подозрительную ссылку: @your_bot` | строка-призыв в конце каждого поста |
| `ANTISCAM_ADD_KYRGYZ` | `true` | короткий пересказ главного совета на кыргызском |
| `ANTISCAM_MODEL` | `claude-sonnet-5-5` | модель Claude. По умолчанию Haiku 5.5: меньше доллара в месяц. Sonnet пишет лучше, но выйдет несколько долларов в месяц |

## Что можно менять

Всё в [`config.yaml`](config.yaml):

| Что | Параметр |
|---|---|
| Сколько постов в день максимум | `daily_limit: 10` |
| Пропорции и порядок рубрик | `plan: [CIS, WORLD, CIS, USA, ...]` |
| Какие рубрики без звука и тихие часы | `silent_categories`, `quiet_hours` |
| Какие страны считаются СНГ | `categories → CIS → describe` и `regions → CIS` |
| Источники, ключевые слова, схемы для напоминаний | `sources`, `keywords`, `evergreen` |

Время запусков задаётся в `.github/workflows/antiscam.yml` (в UTC, это Бишкек минус 6 часов).

## Встроенные правила

ИИ пересказывает своими словами, без цитат и без выдуманных фактов. Он не называет имён, телефонов и карт подозреваемых и потерпевших и пишет «подозреваемый», а не «мошенник». Ссылки на фишинговые сайты бот делает некликабельными: `hxxps://evil[.]site`. Память бота хранится в `data/antiscam_state.json`, поэтому одна история не публикуется дважды.
