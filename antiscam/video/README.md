# 🎬 Ролики к постам antiscam

Workflow **Antiscam video** (`.github/workflows/antiscam-video.yml`) раз в 3 дня (`video.every_days`) выбирает лучший пост канала за этот период — выбор делает Claude: понятная схема, касается многих, ясный урок, приоритет СНГ — и делает по нему вертикальное видео 1080×1920 на 30–40 секунд:

1. **Сценарий** — Claude превращает пост в 6–8 реплик и раскладывает их по готовым сценам (`build.py`).
2. **Озвучка** — голос ElevenLabs: секрет `ELEVENLABS_API_KEY`, голос — `video.voice_id` в `antiscam/config.yaml` (Multilingual v2, stability 0.5, similarity 0.75, style 0). Без ключа — бесплатный голос Piper.
3. **Субтитры** — тайминги слов распознаются моделью GigaAM, слова подсвечиваются по ходу речи.
4. **Анимация** — Remotion, шаблон `src/scam.tsx`: телефон с перепиской, ловушка (файл, ссылка, код, звонок, карта), последствия (SMS, аккаунт, деньги, рассылка друзьям), признаки обмана, как защититься, «Подпишись».
5. **Одобрение** — ролик приходит в личку (`video.admin_chat_id` в config.yaml) с кнопками «✅ Опубликовать» / «❌ Пропустить», плюс подпись для Instagram и текст для Threads. После «Опубликовать» в канале выходит **одно сообщение**: ролик с текстом поста в подписи (сжатым до лимита Telegram 1024 символа), а исходный текстовый пост удаляется. Поэтому ролик делается только по постам не старше 44 часов: позже Telegram не даёт боту удалять сообщения. Пока админ не задан — ролик только в артефактах запуска.

Настройки — раздел `video:` в `antiscam/config.yaml`: сколько роликов в день, из каких рубрик, название и соцсети в конце ролика.

Ручной запуск: **Actions → Antiscam video → Run workflow** (можно указать `post_id` из `data/antiscam_state.json` → `recent_posts`).

Сцены и сценарий: формат — `public/scenario.example.json`. Движок (`engine/`, `src/kit.tsx`, `src/frame.tsx`, `src/tl.ts`) — общий для объясняющих роликов.
